# Blockfall Tetris

A tiny static Tetris-style game built with HTML, CSS, and JavaScript for GitHub Pages.

It is also installable as a small PWA and works offline after the first load.

## Controls

- Arrow left/right: move
- Arrow up: rotate
- Arrow down: soft drop
- Space: hard drop
- P: pause

On phones and tablets, tap the play area to rotate, slide left or right to move, slide down to drop, and flick down to hard drop. The on-screen controls still fit below the board. Hold left, right, or down to repeat the move.
